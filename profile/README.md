# nca-apprentices

The apprentices of NCA build and run these apps together.

| Repository                                                                | What it is                                            |
| ------------------------------------------------------------------------- | ----------------------------------------------------- |
| [ncaleague](https://github.com/nca-apprentices/ncaleague)                 | A table soccer league                                 |
| [jjforge](https://github.com/nca-apprentices/jjforge)                     | A forge for Jujutsu repositories                      |
| [budgetpilot](https://github.com/nca-apprentices/budgetpilot)             | A budget planning app for iOS                         |
| [netgrade](https://github.com/nca-apprentices/netgrade)                   | Grades and exams, on the web, iOS, and Android        |
| [lerndoku-template](https://github.com/nca-apprentices/lerndoku-template) | A template for the apprenticeship's Lerndokumentation |
| [infra](https://github.com/nca-apprentices/infra)                         | The cluster that runs the apps                        |
| [status](https://github.com/nca-apprentices/status)                       | The status page at status.nca-apprentices.dev         |

Read [CONTRIBUTING.md](https://github.com/nca-apprentices/.github/blob/main/CONTRIBUTING.md)
before your first pull request.
